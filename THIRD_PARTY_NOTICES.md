# Third-party source and local changes

The Rust dependency versions and registry checksums are pinned in `Cargo.lock`. Each dependency retains its declared license. MyPDF itself is licensed under MIT OR Apache-2.0 (`LICENSE-MIT`, `LICENSE-APACHE`). A complete license audit of the dependencies is still required before publishing binaries.

## Vendored underskrift

- Package: underskrift 0.1.4
- Source: crates.io release; upstream https://github.com/kushaldas/underskrift
- Upstream commit recorded by the package: `17bca3c4ac49af475772678f1e9ccd35bfaaa3af`
- Declared license: BSD-2-Clause, as recorded in the upstream Cargo manifest
- Local source: `vendor/underskrift`

Local modifications:

1. `src/core/sig_dict.rs`: include `/M` using the claimed local UTC signing time. This does not supply a trusted timestamp.
2. `src/core/incremental.rs`: compute trailer `/Size` as one past the greatest object number, preserving the previous size. Rewriting an existing object must not increase the size merely because it is emitted again.

3. `src/core/sig_dict.rs`, `src/signer.rs`: encode non-ASCII reason/location/contact strings as UTF-16BE hexadecimal PDF strings, keeping ASCII literal escaping.

The upstream package and repository include no standalone license file. `vendor/underskrift/LICENSE` reproduces the standard BSD-2-Clause text that the manifest declares; replace it with the author's own notice if upstream adds one.

The application bypasses the upstream legacy PKCS#12 loader and ECDSA software signer. Its own PKCS#12/key adapters use the `p12-keystore` and RustCrypto libraries. Apple Security APIs remain responsible for native Keychain key operations.

## Desktop viewer dependencies

The viewer uses egui/eframe 0.33.3 (MIT OR Apache-2.0), winit 0.30.13 (Apache-2.0), wgpu 27.0.1 (MIT OR Apache-2.0), rfd 0.17.2 (MIT), and macOS-only muda 0.17.2 (Apache-2.0 OR MIT). Hayro 0.8 provides PDF rasterization and glyph interpretation. These are unmodified registry dependencies. Native operating-system libraries provide the window, menus, file dialogs, Metal/DirectX and clipboard services. The procedural MyPDF icon is generated by this project's Rust source.

## Annotation and artwork dependencies

SVG parsing/rasterization uses resvg/usvg 0.45.1 and tiny-skia 0.11.4 (MIT OR Apache-2.0), with external SVG image resolution explicitly disabled by application options. image 0.25.10 (MIT OR Apache-2.0) decodes PNG/JPEG and embeds normalized artwork. base64 0.22.1 (MIT OR Apache-2.0) supports embedded asset data. These are unmodified registry dependencies. The viewer and exported text appearances use an installed TrueType font; no operating-system font file is shipped in the app bundle. Existing source/rasterization dependencies and transitive font licenses remain part of the release audit.
