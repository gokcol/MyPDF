## Changes and validation

- Read mode accepts single-finger touchscreen panning with bounded flick inertia. Mouse text selection and Shift-click extension remain. Two-finger pan/pinch retains its content anchor; taps still follow links. Touches beginning outside the document are excluded, and release/cancel, view/mode changes, keyboard navigation and explicit page jumps clear or interrupt navigation appropriately.
- Navigation suppresses accidental selections/marks. Repeated layout passes apply pan/pinch/flick once. Protected annotations already in the raster are not painted twice; the active inline draft remains visible while panning. A stationary touch eraser waits for deliberate motion or tap release, allowing a second finger to start navigation without erasing ink. Immediate mouse erasing and completed deliberate touch erasing remain intact.
- Reading-state writes wait for 600 ms of quiet, with a ten-second checkpoint and retry after failure. Workspace writes wait during navigation; approved close/exit flushes pending state. Cache candidates are sorted only when over budget, and text indexing decodes each glyph outline once.
- The MyPDF logo, MyPDF title text and eligible empty tab-strip area share window-drag behavior: an open-hand cursor on hover, a closed hand while pressed/dragging, and a native window move after the drag threshold. Document tabs, close buttons and other controls retain their own gestures; dragging into the strip from elsewhere does not start a window move. Full-screen windows and open popups suppress this gesture. macOS sets the closed hand before entering its blocking native drag loop and restores hover feedback afterward.
- Existing rich clipboard formatting, verified ligature recovery, duplicate-paint suppression, image copying, standard mouse/Shift-click selection and the search-clear X remain. Ligature recovery still requires a matching locally available font; no private PDF or additional font was bundled.

Local final validation passed: formatting, Clippy with warnings denied, and cargo test --locked --no-fail-fast: **704 passed, 0 failed, 7 ignored** across 39 suites. Regression coverage includes native Touch plus emulated pointer input, link taps, pinch anchoring, cancellation, outside contacts, repeated layout, annotation painting, staggered eraser navigation, mouse/Shift-click selection and erasing. Persistence coverage includes idle writes, checkpoint/retry, temporarily unavailable source files and normal-close flushing. Window-drag coverage includes logo/title/empty-strip cursor feedback, movement threshold, child-control ownership, popup/full-screen suppression and release handling; final results must come from this release source.

The reported Windows 11 laptop has an Intel i7 and 16 GB RAM. **Physical Windows touchscreen/pen behavior, native window-drag cursor display and end-to-end scrolling speed have not been verified on that laptop.** Headless gesture/cursor tests and CI do not establish how the Windows cursor appears during its native move loop. Those results are backend measurements, not Windows scrolling/frame-rate measurements. Receipt: `artifacts/windows-touch-performance/extraction-benchmark.json`.
